# atcoder-cheat-sheet

AtCoder用の個人チートシートです。Pythonのコード例、学習メモ、VS Code用スニペットを置いています。

- `0.py`, `0-input.txt`：問題を解くための作業用ファイル。
  `python 0.py < 0-input.txt` で実行します。
- 各フォルダ：アルゴリズムや標準ライブラリのコード例
- `.vscode/python.code-snippets`：Python用スニペット

学習・試行途中のコードを含みます。
